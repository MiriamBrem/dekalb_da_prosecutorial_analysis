# DeKalb County DA Prosecutorial Analysis
Statistical analysis for the DeKalb County District Attorney's Office examining trial line burden and prosecutorial efficiency

## Overview

This project analyzes the DeKalb County District Attorney’s Office Trial Division using Prosecutorial Performance Indicators (PPIs). The analysis examines case distribution, processing timelines, and serious crime outcomes to better understand prosecutorial workload.

**Research Question:** Is the Trial Division overburdened, and what factors contribute to its workload?

## Key Findings

The analysis did not provide sufficient evidence to conclude that the Trial Division is definitively overburdened. Cases are distributed through a quasi-random assignment process, while differences in staffing limit comparisons between divisions. Pending cases remain high but have declined following the COVID-19 period. Case processing times vary across stages of the judicial process, and serious crime outcomes differ across offense types.

## Methods
The analysis examined three Prosecutorial Performance Indicators:

**Organizational & Staff Capacity:** Case distribution across attorneys and divisions 
**Timeliness & Case Processing:** Pending cases and resolution timelines
**Addressing Serious Crime:** Outcomes for serious violent offenses

The project involved cleaning and transforming real-world administrative data in R, followed by exploratory analysis and data visualization.
